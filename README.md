# 💊 Pharma Sales & Demand Intelligence Dashboard

📊 An end-to-end **Pharma Sales & Demand Analytics** project built using **Python, SQL, Power BI, and DAX** to analyze sales trends, drug categories, demand intensity, and market share.

---

## 🛠️ Tools & Technologies

- 🐍 **Python** – Data cleaning and preprocessing
- 🗄️ **SQL** – Data transformation and feature engineering
- 🔀 **CASE WHEN** – Created business-based categories
- 📈 **Window Functions** – Trend and analytical calculations
- 📊 **Power BI** – Interactive dashboard and visualization
- 🧮 **DAX** – Created dynamic dashboard metrics

---

## 🔄 Project Workflow

**Raw Data → Python Cleaning → SQL Feature Engineering → Power BI → DAX → Interactive Dashboard**

---

## 🐍 Python – Data Cleaning

Python was used to prepare the raw pharma sales data for analysis.

Key activities:

- Cleaned and standardized the dataset
- Handled missing and duplicate values
- Checked data types
- Prepared the data for SQL analysis

---

## 🗄️ SQL – Feature Engineering

SQL was used to transform the cleaned data and create useful analytical features.

Key techniques:

- Aggregations and grouping
- `CASE WHEN` for demand/category classification
- Window Functions for analytical calculations
- Trend and ranking analysis

---

## 📊 Power BI Dashboard

The dashboard provides an interactive view of pharma sales and demand performance.

### Key Dashboard Metrics

- 💰 Total Sales Volume – **126.71K**
- 📅 Average Daily Sales – **7.57**
- ⚡ Spike Ratio – **72.04%**
- 🔥 High Demand Days – **4,409**

### Dashboard Visuals

- 📈 7-Day Moving Average vs Daily Sales
- 💊 Drug Category Market Share
- 📊 Seasonal Sales Trends by Quarter
- 🔥 Demand Intensity by Drug Category
- 🎯 Interactive Date and Category Filters

---

## 🧮 DAX Measures

DAX was used to create dynamic metrics for the dashboard, including:

- Total Sales Volume
- Average Daily Sales
- Market Share %
- High Demand Days
- Spike Ratio %
- Other dashboard KPIs

These measures make the dashboard interactive and responsive to filters.
